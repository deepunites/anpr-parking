ANPR Parking — локальный запуск на Windows
==========================================

Что нужно (один раз)
--------------------
1. Windows 10 (21H2+) или Windows 11, 64-бит; 8 ГБ ОЗУ (лучше 16), 10 ГБ на диске, интернет для первой сборки.
2. Docker Desktop: https://www.docker.com/products/docker-desktop/
   При установке оставьте «Use WSL 2». Если Docker попросит включить виртуализацию или обновить WSL —
   согласитесь и перезагрузите компьютер.

Запуск
------
Распакуйте архив в папку без кириллицы и пробелов в пути (например, C:\anpr-parking) и дважды щёлкните START.bat.

Первый запуск — 5–15 минут: собираются образы, создаётся база, загружаются демо-данные. Затем:
  • откроется браузер на http://localhost:8080;
  • рядом с START.bat появится LOGINS.txt — логины, пароли и ключи камер (пароли случайные, свои на каждом компьютере).
Следующие запуски — около минуты. После перезагрузки Windows стенд поднимается сам, если в Docker Desktop
включено «Start Docker Desktop when you sign in» (Settings → General).

Кто есть в демо-данных
----------------------
  platform@alpha-parking.uz — владелец платформы: клиенты, тарифы, отметка оплаты наличными;
  admin@alpha-parking.uz    — администратор клиента «Alpha Parking» (2 площадки, камеры, тарифы);
  operator / cashier / manager / owner @alpha-parking.uz — роли сотрудников;
  admin@beta-garage.uz      — второй клиент (данные клиентов изолированы друг от друга).
В демо-данных есть неделя работы «Alpha Parking»: ~250 въездов и оплат наличными, смены кассиров (в одной —
недостача 50 000 сум) и ручные открытия стрелы. Их видно в «Сводке» (вход owner@ или admin@) — вместе с сигналами
«Расхождение кассы» и «Много ручных открытий». Не нужны — перед первым запуском задайте STAND_DEMO_WEEK=0.
Новый клиент регистрируется сам: http://localhost:8080/signup — SMS не подключены, код подтверждения
показывается прямо на экране.
Сотрудников приглашайте в разделе «Сотрудники» → «Пригласить по ссылке»: ссылку можно отправить в Telegram,
WhatsApp или SMS, сотрудник сам придумает пароль. Входить можно по e-mail или телефону.

Файлы
-----
  START.bat — собрать и запустить (повторный запуск применяет обновления кода и миграции базы);
  STOP.bat  — остановить, данные сохраняются;
  LOGS.bat  — журналы всех сервисов (для разбора проблем);
  RESET.bat — удалить ВСЕ данные стенда и начать с нуля (спросит подтверждение).

Доступ из локальной сети и камеры
---------------------------------
Веб открыт на порту 8080 всех сетевых интерфейсов: с планшета или другого компьютера — http://<IP этого ПК>:8080
(при первом запуске Windows может спросить разрешение для Docker в брандмауэре).
Камеры отправляют распознанные номера на http://<IP этого ПК>:8080/api/v1/camera/... с ключом из LOGINS.txt
в заголовке X-Camera-Key (адреса для Hikvision и Dahua — там же). Новые камеры и ключи — в разделе «Устройства».

Шлагбаум и сетевое реле
-----------------------
В демо-данных «ТЦ Mega, въезд 1» управляется имитатором сетевого Modbus-реле: страница стрелы —
http://localhost:8098 (только с этого компьютера). В разделе «Устройства» → «Шлагбаумы»:
  «Проверить связь» — читает реле, стрела не двигается;  «Открыть для проверки» — ждёт, пока стрела откроется.
Настоящий шлагбаум (APOLLO и подобные с контактами OPEN/COM) подключается через Ethernet-реле с Modbus TCP,
например Waveshare Modbus POE ETH Relay: канал 1 (NO/COM) → клеммы OPEN и COM платы шлагбаума.
В системе: подсеть реле — в настройках площадки («Подсети контроллеров стрел»), шлагбаум — драйвер Modbus TCP,
адрес вида 192.168.1.200:502?unit=1&open_coil=0&pulse_ms=500. Закрывает стрелу сам шлагбаум (петля/таймер).

Другой порт
-----------
Если порт 8080 занят, в командной строке в папке проекта:
  set PARKING_HTTP_PORT=8090
  START.bat

Что внутри
----------
deploy\local\compose.yml — PostgreSQL 16, Redis 7, MinIO (фото с камер), API, воркеры (publisher, consumer,
replayer, camera-health), Celery worker и beat, обслуживание партиций, веб на nginx. Наружу открыт только веб;
база, Redis и MinIO доступны лишь внутри Docker. Секреты (ключи шифрования номеров, JWT, пароли БД) создаются
при первом запуске и хранятся в томе Docker «state» — RESET.bat удаляет их вместе с базой.

Ограничения локального стенда
-----------------------------
  • коды регистрации показываются на экране (нет SMS/Telegram), пароли сбрасывает администратор;
  • фото с камер сохраняются в MinIO, но в браузере на этом стенде не показываются;
  • демо-шлагбаумы из примера выключены — настоящие контроллеры добавляются в «Устройствах»;
  • это стенд для показа и пилота на одном компьютере, не production (для него — deploy\helm и docs\RUNBOOK.md).

Работает и на Linux/macOS с Docker:
  docker compose -f deploy/local/compose.yml up -d --build
