# Сервер парковки на TrueNAS

Система работает на маленьком сервере прямо на парковке: камера, стрела и телефоны кассиров — в одной сети с ним
(у MediaPark — 192.168.13.x, роутер 192.168.13.1). Интернет нужен только при установке и обновлении.

**Что нужно**
- компьютер x86-64, 16 ГБ памяти, **отдельный** загрузочный SSD от 32 ГБ и диск (лучше два одинаковых) для данных;
- кабель в сеть парковки (тот же роутер/свич, что у камер), флешка от 8 ГБ;
- 40–60 минут.

## 1. Установка TrueNAS

1. Скачайте ISO **TrueNAS Community Edition 25.10** — https://www.truenas.com/download-tn-scale (бесплатно).
2. Запишите на флешку: balenaEtcher или Rufus (режим DD).
3. Загрузите сервер с флешки → **Install/Upgrade** → выберите **загрузочный SSD** (не диск данных — он будет стёрт)
   → **Administrative user (truenas_admin)** → придумайте пароль → дождитесь конца, выньте флешку, перезагрузите.
4. На экране сервера появится адрес веб-интерфейса, например `http://192.168.13.57`. Откройте его в браузере
   с компьютера в этой же сети и войдите: `truenas_admin` и пароль из шага 3.

## 2. Постоянный адрес сервера — 192.168.13.20

Камера и телефоны ходят на сервер по адресу, он не должен меняться.

1. Убедитесь, что адрес свободен: в списке клиентов роутера 192.168.13.1 его нет (или `ping 192.168.13.20` молчит).
2. **Network → Interfaces →** сетевая карта → **Edit**: снимите **DHCP**, **Aliases → Add** → `192.168.13.20` / `24`
   → **Save** → **Test Changes** → в течение минуты откройте `http://192.168.13.20` и нажмите **Save Changes**.
3. **Network → Global Configuration**: Default Gateway `192.168.13.1`, Nameserver 1 `192.168.13.1`,
   Nameserver 2 `8.8.8.8` → **Save**.

## 3. Диски и Docker

1. **Storage → Create Pool**: имя `tank`, диски данных (два — **Mirror**, один — **Stripe**).
2. **Datasets → tank → Add Dataset**: имя `anpr`, Dataset Preset — **Generic**.
3. **Apps → Configuration → Choose Pool** → `tank` → **Save**. Дождитесь «Apps Service Running» — так включается
   Docker, на котором работает парковка.

## 4. Программа парковки на сервер

**System → Shell** (оболочка в браузере):

```bash
sudo git clone https://github.com/deepunites/anpr-parking.git /mnt/tank/anpr/anpr-parking
```

Если `git` не найден — тот же код архивом:

```bash
sudo mkdir -p /mnt/tank/anpr/anpr-parking && curl -L https://github.com/deepunites/anpr-parking/archive/refs/heads/main.tar.gz | sudo tar xz --strip-components=1 -C /mnt/tank/anpr/anpr-parking
```

## 5. Установка

```bash
sudo bash /mnt/tank/anpr/anpr-parking/deploy/truenas/install.sh
```

Первый раз — 5–15 минут: сборка, база, компания MediaPark, площадка на 54 места с подсетью 192.168.13.0/24,
камера въезда с ключом, стартовый тариф. Демо-данных нет, регистрация чужих компаний выключена. В конце скрипт
покажет адрес панели и логин администратора; они же — в `/mnt/tank/anpr/anpr-parking/deploy/truenas/LOGINS.txt`
(`sudo cat …`).

Другие название, число мест, подсеть или логин администратора задаются **до первой установки** (потом — в панели):

```bash
sudo cp /mnt/tank/anpr/anpr-parking/deploy/truenas/parking.env.example /mnt/tank/anpr/anpr-parking/deploy/truenas/parking.env
```

```bash
sudo nano /mnt/tank/anpr/anpr-parking/deploy/truenas/parking.env
```

Сервисы сами поднимаются после перезагрузки сервера. В разделе Apps TrueNAS их не видно — это нормально, они
запущены скриптом. Журналы: `sudo bash …/deploy/truenas/logs.sh` (или `logs.sh api`), остановить — `stop.sh`.

## 6. Первый вход

`http://192.168.13.20:8080` → логин `admin@mediapark.uz` и пароль из LOGINS.txt → система попросит задать свой.

**Забыли пароль администратора** (пароль из LOGINS.txt после смены больше не действует): **System → Shell** →

```bash
sudo bash /mnt/tank/anpr/anpr-parking/deploy/truenas/reset-admin.sh
```

Новый временный пароль появится только на экране консоли; при входе система попросит задать свой, прежние сессии
завершатся, сброс попадёт в журнал аудита. Другому сотруднику — его логин после команды (e-mail или телефон).
Обычно пароль сотруднику сбрасывает администратор в панели: «Сотрудники» → «Сбросить пароль».

## 7. Камера и стрела

1. **Адрес камеры** должен быть из сети парковки, например `192.168.13.250`, шлюз `192.168.13.1` (SADP Tool,
   Hik-Partner Pro или веб-интерфейс камеры — нужен пароль admin камеры).
2. **В камере** (`http://192.168.13.250`): **Сеть → Подключение данных → Проверка ISAPI → ISAPI1**: включить, HTTP,
   IP `192.168.13.20`, порт `8080`, «URL хоста» — строка из LOGINS.txt (`/api/v1/camera/vendor/hikvision/<ключ>`),
   изображение номерного знака, аутентификация — нет, **«Проверка ответа платформы» — включить**, интервал
   контрольных сигналов 60. **Система → Настройки времени**: NTP `pool.ntp.org`, GMT+05:00, летнее время выключить.
3. **В панели: Устройства → Стрелы → Добавить стрелу**: драйвер «Камера Hikvision», адрес `http://192.168.13.250`,
   камера «Въезд 1», логин и пароль камеры → **Проверить связь** (стрела не двигается) → **Открыть для проверки**.
4. Через минуту камера в «Устройствах» станет «в сети». Провода стрелы — **только реле 1**: 1A → «открыть»,
   1B → общий провод входов платы: у платы «digital system» (MediaPark) — клемма `12V` (входы срабатывают от
   +12 В), у платы V3.0 — `GND`. Реле 2 к «закрыть» **не подключать**: камера, увидев машину, сама замыкает реле 2 и
   отменяет открытие. Закрывает плата сама — таймером или петлёй (клеммы плат — в `docs/DEVICES.md` §3.4).
5. В «Устройствах» у камеры — «Пороги распознавания»: ночью и под землёй камера даёт уверенность 60–80; с порогом 80
   (по умолчанию) каждый въезд уходит кассиру. На MediaPark — 60 / 40.

## 8. Кассиры с телефонов

Панель работает по `http://` без шифрования: пароли сотрудников и ключи камер идут по сети открыто. Телефоны кассиров,
сервер и камеры держите в **служебной** сети/Wi-Fi, не в гостевом Wi-Fi для посетителей.

Телефон в служебном Wi-Fi парковки → `http://192.168.13.20:8080`. Сотрудники: **Сотрудники → Пригласить по ссылке** (роль
«Кассир») — ссылку отправить в Telegram, сотрудник сам задаст пароль.

## 9. Резервные копии

- **System → Advanced Settings → Cron Jobs → Add**: команда
  `bash /mnt/tank/anpr/anpr-parking/deploy/truenas/backup.sh`, Run As User `root`, каждый день в 03:00.
  Копии — в `/mnt/tank/anpr/backup` (база + ключи шифрования), хранятся 14 дней.
- **Data Protection → Periodic Snapshot Tasks → Add**: dataset `tank/anpr`, ежедневно, хранить 2 недели.
- В копиях ключи шифрования номеров и пароли — никуда их не выкладывайте; лучше копировать на второй диск/флешку.

## 10. Видеозапись камер

Камера DS-TCG406-E сама на сетевой диск не пишет (в прошивке нет NAS), поэтому видео записывает сервер: забирает
поток каждой камеры и режет его на 10-минутные файлы без перекодирования —
`/mnt/records/cam-entry/2026-10-12/15-40-00.mp4` (въезд), `cam-exit` — выезд. В карточке сессии (поиск по номеру,
«Живая парковка») кнопки **Видео: Въезд / Выезд** показывают ролик от 10 с до события до 20 с после.

Адрес, логин и пароль для записи: у камеры со своей стрелой «Камера Hikvision» — те же, что у стрелы (вводить не
нужно). Камере без стрелы — **«Устройства» → камера → кнопка «Видеозапись»** (видеокамера): адрес `http://IP камеры`,
логин и пароль пользователя камеры (лучше отдельного, только с правом просмотра).

**Одна стрела на въезд и выезд.** Провода стрелы — только от реле камеры въезда; у выездной камеры своей стрелы нет.
При выезде сервер открывает стрелу камеры выезда, а если её нет — единственную стрелу площадки, то есть через реле
камеры въезда. У обеих камер в настройках распознавания — направление «Вперёд» (только приближающиеся машины), иначе
камера въезда прочтёт задний номер выезжающей машины как въезд.

1. **Диск под видео** — лучше отдельный HDD: **Storage → Create Pool** → имя `records` (один диск — Stripe; второй
   такой же потом добавляется через **Manage Devices → Extend**, получится Mirror).
2. **Datasets → records → Add Dataset**: `cam-entry` и `cam-exit`, у каждого **Quota** — чуть меньше половины пула
   (на 1 ТБ — 420 GiB). Основной поток 4 Мбит/с — около 41 ГБ в сутки: 420 GiB хватает на 10 суток.
3. Включить запись:

   ```bash
   sudo bash /mnt/tank/anpr/anpr-parking/deploy/truenas/video.sh
   ```

   Через полминуты скрипт покажет, сколько записано по каждой камере. Проверить позже — `video.sh status`,
   выключить — `video.sh off` (файлы остаются). После новой камеры или смены её «Видеозаписи» в «Устройствах» —
   запустить `video.sh` ещё раз (если ничего не поменялось, запись не перезапускается).

Старое удаляется само: записи старше `PARKING_VIDEO_KEEP_DAYS` (30) дней и самые старые часы, когда раздел заполнен
больше чем на 90 %. Поток, папка и сроки — в `parking.env` (`PARKING_VIDEO_*`). Связь с камерой пропала — запись
переподключается каждые 10 секунд.

Все записи целиком — с компьютера по сети: **Credentials → Users → Add** — пользователь `video` (пароль задаёте
сами, «SMB User» — да, оболочка — нет); **Shares → SMB → Add** — `/mnt/records/cam-entry` и `/mnt/records/cam-exit`,
только чтение, доступ — пользователю `video`. В Windows: `\\192.168.13.20\cam-entry` → логин `video`; файлы
открываются в VLC или «Кино и ТВ». Папку `/mnt/records/backup` не открывать: там копии базы и ключи шифрования.

## 11. Обновление

```bash
cd /mnt/tank/anpr/anpr-parking && sudo git pull && sudo bash deploy/truenas/install.sh
```

Данные, пароли и ключи камер сохраняются; новые миграции базы применяются сами.
